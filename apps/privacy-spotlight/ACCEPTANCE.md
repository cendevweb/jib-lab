# Privacy Spotlight — Acceptance criteria

Every criterion is binary and has at least one test whose title contains `[AC-xx]`.
`pnpm verify privacy-spotlight` fails if any AC id below is not referenced by a test.
Section numbers (§) refer to SPEC.md. Unit tests run in jsdom (no layout): DOM tests inject
`measure`. E2E runs at 1440×900 against `next start`. Vendor-prefixed token fixtures are built by
string concatenation (SPEC §3).
