# Jev Agent Air-Traffic Controller — Acceptance criteria

Every criterion is binary and has at least one test whose title contains `[AC-xx]`.
`pnpm verify jev-agent-atc` fails if any AC id below is not referenced by a test.
Section numbers (§) refer to SPEC.md. Scenario checkpoints use `runScenario()` with the default
seed; `frameAt`-style lookups mean `run.frames[t / 500]`.
